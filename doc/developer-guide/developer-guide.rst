.. _lsst.ts.dynalenegui-modules_dynalenegui:

dynalenegui
-----------

.. mermaid:: ../uml/class_dynalenegui.mmd
    :caption: Class diagram of Dynalene GUI

* **MainWindow** is the main window of the application. It holds the tabs that are opened from its list of windows.
* **TabTemplate** is the base class of all the tabs (from ts_guitool).

.. _lsst.ts.dynalenegui-modules_dynalenegui_tab:

dynalenegui.tab
---------------

.. mermaid:: ../uml/tab/class_tab.mmd
    :caption: Class diagram of tab module

All the tabs inherit from **TabTemplate** of ts_guitool.
Each tab is a window opened from the main window.
